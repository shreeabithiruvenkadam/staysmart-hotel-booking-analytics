STAYSMART — Hotel Booking Analytics

Project Overview
This project analyses hotel booking data using Microsoft Excel to explore booking patterns, estimated revenue, and cancellation behaviour.

Objectives
- Compare City Hotel and Resort Hotel bookings.
- Analyse estimated revenue and cancellation rates.
- Explore booking trends and guest behaviour.
- Present key metrics using Excel PivotTables and charts.

Tools Used
- Microsoft Excel
- Data cleaning
- PivotTables
- Charts and data analysis

Dataset
Hotel Booking Demand dataset.

Source: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

Data Preparation
- Reviewed missing values and inconsistent records.
- Prepared relevant fields for booking and stay analysis.
- Created calculated columns for guest counts, stay duration, estimated revenue, and cancellation status.

Key Results
- Valid booking records analysed: 87,230
- City Hotel bookings: 53,274
- Resort Hotel bookings: 33,956
